# Studio dark tabs implementation plan

> Use executing-plans inline for the coupled shell/dashboard bridge and CSS
> verification. Independent reviewers remain read-only.

**Goal:** join dark active tabs and loading to the editor surface, and let native
About follow the selected appearance without replacing it.

**Architecture:** existing bg-surface token, plus one allowlisted theme preference
message from the tabs shell to nativeTheme. No new persisted state.

**Tech stack:** React, Tailwind, Vitest, Electron 11, Node assertions.
